# Spinarium concept artwork

These assets were generated specifically for the first Spinarium milestone on 2026-10-01 using OpenAI image generation. They are original, replaceable visual placeholders, not approved Veiling artwork or finalized SpinDownGames canon.

The dashboard reference guided atmosphere, composition and palette. The reference screenshot was not copied, cropped, embedded or used as a webpage background. Each file is a standalone illustration containing no interface or text.

Generated PNG sources remain in the workspace's `/workspace/generated_images/` directory; WebP copies are stored here for website use. WebP conversion preserves the full generated composition. No existing SpinDownGames artwork was modified.

Artwork belongs in the replaceable mock asset layer. Production Veiling definitions should resolve separate artwork roles through the service boundary: engraving, color, silhouette, thumbnail, variant and optional 3D assets. Replacing concept artwork should require an asset path/data change, not a component rewrite.

The shared `silhouette.webp` is intentionally a generic black creature outline against charcoal mist. It may represent any undiscovered character, including through harmless horizontal-flip variations; it does not encode or expose a hidden Veiling's actual appearance.
